# Notes REST API

## Description

This project is a REST API built with PHP and MySQL to manage personal notes.
It supports full CRUD operations (Create, Read, Update, Delete) and works with JSON data.

Each note includes title, author, date and time, content, and classification.


## Technologies

* PHP
* MySQL
* XAMPP
* Postman
